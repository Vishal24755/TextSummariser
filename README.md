# Application 05: Text Summarizer

An extractive text summarizer that identifies and extracts the most salient sentences from paragraphs and articles.

## Features
- **Extractive Sentence Ranking:** Scores sentences based on normalized word frequencies while penalizing sentence length bias.
- **Customizable Summary Length:** Choose between Top 2 Sentences, Top 3 Sentences, ~30% of Original, or ~50% of Original.
- **Side-by-Side Comparison:** Displays original text and extracted summary.
- **Word Count Metrics:** Compares original word count, summary word count, and percentage reduction.
- **Copy and Clear:** Easy one-click buttons to copy the generated summary or clear the editor.

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla ES6)

## How to Run
Double-click `RUN.bat` or open `index.html` directly in any web browser.
